Title: [needs-packaging] udb - Ubuntu development-environment initializer
Tag: needs-packaging

Description:
udb (Ubuntu Development Bootstrap) helps ordinary users initialize an Ubuntu
development environment on standalone Ubuntu or WSL2. It contains no default
organization-specific tenant or internal tool installer.

Package installation copies the command and documentation only. There are no
package maintainer scripts that initialize the host, accept third-party EULAs,
log into accounts, or change privilege policy. Users invoke initialization
separately as an ordinary user.

Notes for review:
- Confirm archive/component suitability for any proprietary-tool integrations.
- Review explicit-run side effects: apt upgrades, WSL passwordless sudo, Docker
  group access, Copilot --yolo aliases, and WorkIQ EULA acceptance.
- The source rejects non-Ubuntu distributions; assess Ubuntu-direct submission
  rather than assuming it is currently a Debian-compatible initializer.
- This is a request for packaging/sponsorship review, not a claim of archive
  acceptance. The unsigned upstream source package uses a noble changelog
  target for the release preview; the sponsor must select the actual eligible
  Ubuntu release/version for upload.
- The current Ubuntu development series is tenacious (27.04). Runtime support
  for that series has not been validated; the supported-runtime guard currently
  permits 22.04, 24.04, and 26.04 only. This must be resolved before an upload
  intended to run on 27.04, not bypassed by claiming untested support.
- Never attach bootstrap run logs, credentials, account identifiers, shell
  configuration, or local backups to a public request.
- The package name and related requests must be checked before filing.
